# MoneyMan product context

## Register

product

## Users and purpose

People tracking expenses and savings on their own devices, plus portfolio reviewers
who need to explore the product without personal financial information. The main
workflow is entering or importing transactions, reviewing monthly spending, and
planning savings goals.

## Existing identity

A restrained, mobile-first interface inspired by native iOS. Preserve the current
components, system typography, light/dark themes and Reicon interface icons.
Avoid a marketing-page redesign, new UI frameworks or decorative dashboards.

## Design principles

- Keep financial data local and demo data separate from personal records.
- Make the first useful dashboard easy to reach.
- Explain destructive actions and keep their scope explicit.
- Preserve manual entry, CSV import and navigation.
- Keep Spanish UI for now; new demo controls include English and Spanish.

## Accessibility

Preserve keyboard access, visible focus, readable labels, safe-area handling and
reduced-motion preferences. Phase 1 does not claim a completed accessibility audit.
