# Portfolio screenshots / Capturas de portfolio

Only the built-in synthetic demo may appear in committed screenshots.
Usar únicamente la demo ficticia integrada en las capturas del repositorio.

- `dashboard-mobile.png`: current-month dashboard, 390 × 844 viewport.
- `dashboard-desktop.png`: dashboard, 1440 × 900 viewport.

These capture the current Spanish interface with bilingual demo controls. Dates
follow the month of capture. Neither image uses imported or personal records.

To refresh: open a clean local browser tab, choose Try demo / Probar demo, reset
the demo, and capture Panel at the sizes above. Keep the synthetic-data banner
visible. Capture Meta and Gastos separately if you need a longer product walkthrough.
The app scrolls internally, so a browser full-page screenshot will not necessarily
capture everything below the fold.

Para actualizar: abrir una pestaña local limpia, cargar y restablecer la demo y
capturar Panel en esos tamaños. Mantener visible el aviso de datos ficticios.
Para un recorrido más largo, añadir capturas de Meta y Gastos. El scroll es interno;
una captura de página completa no recoge necesariamente todo su contenido.

Pending manual assets: installed PWA on physical iOS/Android devices after the
installation icons are fixed. Pendientes: capturas de la PWA instalada en móviles
reales tras resolver los iconos.
